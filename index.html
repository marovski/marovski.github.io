Featured Projects

Simulador Crédito CV

Problem

Lack of an accessible tool to calculate the real cost of a loan in Cabo Verde — not just the monthly payment, but the TAEG (Annual Effective Rate), which reflects fees and insurance.

Solution

Web app with interactive sliders to simulate monthly payments and TAEG, expandable amortization tables, side-by-side scenario comparison, bilingual interface (PT/EN) and dark mode. All calculations run in the browser — no data is sent to a server — and it installs as a PWA for offline use.

Technologies
HTML5 CSS3 JavaScript ES6+ PWA
Result

Version 4.0, actively maintained, installable on Android/iOS/desktop, supported on Chrome, Firefox, Safari and Edge. Over 430 active users and 1,200 views since the start of the year.

Cantinho C — Booking Platform

Problem

Cantinho C needed a direct booking and payment channel, in Cape Verdean Escudos, without relying solely on third-party channels.

Solution

Custom booking platform with real-time availability checks, booking creation, payment initiation and confirmation, a guest self-service portal to view/cancel bookings, email notifications, and an admin dashboard — content managed via a headless CMS.

Technologies
Next.js 16 TypeScript Tailwind CSS Framer Motion Sanity CMS SISP (3D Secure)
Result

Platform in production, generating roughly 30,000 CVE in revenue directly through the site.
